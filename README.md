# Mike Winters — Program & Project Management

**Portfolio:** [mikewinters.netlify.app](https://mikewinters.netlify.app)

Program and operations leadership portfolio focused on program planning, quality systems, human evaluation, team development, and AI data operations.

## Portfolio sections

The site includes four program case studies; illustrative dashboards and SQL examples using synthetic data; Seattle Link Light Rail analysis; Tower of Query, a SQL learning game; and a Netlify contact form. The resume is served from `/resume.pdf`.

## Stack and deployment

React, TypeScript, Vite, Tailwind CSS, and Netlify. Production deployment is managed by the owner.

## Local development

Run `pnpm install` and `pnpm dev` to start the local site. Use `pnpm check` for TypeScript validation and `pnpm build` for a production build. Netlify publishes `dist/public` as configured in `netlify.toml`.
